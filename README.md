# 🍕 Pizza Sales Analysis Project
![pizza (1)](https://github.com/user-attachments/assets/b9e0a549-dd69-4312-b458-c3ac9843f74b)

## 📝 Project Overview
The Pizza Sales Analysis project provides a comprehensive breakdown of a pizza restaurant’s sales performance. Using dynamic dashboards, this project visualizes:

- ✔️ Total revenue
- ✔️ Order patterns
- ✔️ Peak sales hours
- ✔️ Weekly trends
- ✔️ Product-level performance

💡 With data-driven insights, restaurants can optimize menu offerings, improve inventory planning, and enhance revenue strategies.

This project includes **three dynamic dashboards** created with Tableau, supported by a backend built on MS SQL Server.

---

## 🛠️ Tech Stack
- 🗄️ **SQL Server** – Data storage & preprocessing  
- 📊 **Tableau** – Interactive dashboards & reporting  
- 📈 **PowerPoint** – Presentation of insights

---

## 🎯 Problem Statement
The objective of this project is to:

- 📈 Analyze total revenue, order volume, and pizza category performance  
- ⏰ Identify peak sales periods (hourly, weekly, monthly trends)  
- 🍕 Compare top-performing vs worst-performing pizzas (revenue & orders)  
- 👥 Understand customer demand patterns for smarter menu decisions  
- 🧠 Provide summary and granular insights for strategic planning

---

## 📊 Dashboard Details

### 🔹 Dashboard 1 — Summary
Provides a high-level overview of core pizza sales metrics.

**Key KPIs:**
- 💰 Total Revenue (MTD & MoM change)  
- 🧾 Total Orders (MTD & MoM change)  
- 📦 Average Order Value (AOV)  
- 🍕 Total Pizzas Sold (MTD & MoM change)  
- 🏆 Top Category Contribution (Classic, Supreme, Veggie, etc.)  
- 🔥 Best vs Worst Performers  
- ⭐ Top-Selling Pizzas (Revenue & Quantity)  
- ❗ Lowest-Selling Pizzas  
- 🏅 Top Category  
- ⚠ Underperforming Categories  

**Sales Grid View Includes:** Revenue, Total Orders, Quantity Sold, Avg Price, Contribution %

### 🔹 Dashboard 2 — Overview
Visualizes trends across time, category, and size.

| Chart Type | Metrics | Purpose |
|------------|--------|--------|
| 📈 Line Chart | Revenue, Orders | Monthly & Weekly trends |
| 🌊 Area Chart | Hourly Revenue | Identify peak sale hours |
| 📊 Bar Chart | Revenue, Qty Sold | Category performance |
| 📏 Bar Chart | Revenue, Orders | Size performance (S, M, L, XL) |
| 🟩 Treemap | Revenue, Qty Sold | Contribution by pizza name |
| 🍩 Donut Chart | Orders & Revenue | Day-of-week performance |

### 🔹 Dashboard 3 — Detailed View
Granular breakdown of pizza sales:

- 🍕 Pizza-wise detailed performance  
- 📦 Category / Size / Menu analytics  
- ⏱ Hourly & daily filters  
- 💲 Revenue contribution by pizza  
- 🔍 Dynamic drill-down options  
- 🧾 Full transaction-level view
